# Tags

Tags group articles by topic, without a hierarchy. They are managed in the admin, under **Blog › Tags**.

| Field | | Notes |
| --- | --- | --- |
| Code | Required | Unique. Letters, numbers, dashes and underscores. It can't be changed later. |
| Name | Required, per locale | |
| Slug | Required, per locale | Unique per locale. The button next to it generates it from the name. |
| Meta title and description | Per locale | |

Deleting a tag removes it from the articles that use it.
